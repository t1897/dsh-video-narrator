# 03 · Metadata Prompt

```text
根据口播稿生成严格 JSON（不要 Markdown，不要代码块）：{"title","description","tags"}。

title：
- 12–30 个中文字符；具体对象 + 悬念/反差；像点击标题，不要普通总结。
- 不夸大、不编造、不剧透结局；不含 / \ : * ? " < > |；不加书名号/引号。

description：
- 2–3 句；交代人物处境、冲突升级、未解问题；结尾留一个问题。
- 不写完整剧情，不揭晓结局。

tags：
- 恰好 10 个；3 个宽泛、4 个主题、3 个长尾。
- 不带 #；英文小写；中文 1–4 字；不要重复。

脚本：
{{script_json}}
```

**校验**：title 非空且 ≤ 40 字符；tags 恰好 10 个；description 50–300 字。
