# 01 · 文稿清洗 Prompt

```text
你是专业文字编辑。输入可能是视频逐字稿、网页正文、PDF 文本或用户粘贴的纯文本。
请整理成结构清晰的 Markdown 文稿。

规则：
1. 去掉导航、订阅/登录提示、广告、推荐阅读、评论区、页脚、版权、社交按钮等非正文。
2. 修正明显的 ASR 错字/同音字；不确定的专有名词保留原样，并在旁边标注 [?]。
3. 按主题分段，加一级/二级标题；保留事实、数字、人物关系、时间线和关键转折。
4. 不编造原文没有的信息；不总结成摘要；不输出处理说明；不添加“作为 AI”之类的话。
5. 如果原文是口语，保留口语信息，但去掉“呃/那个/就是说”等无意义口头禅。

输出：只输出 Markdown 正文。

原始文本：
{{transcript}}
```

**校验**：至少 1 个 Markdown 标题；长度是原文的 0.5–1.1 倍；不含“处理说明”“以下是”。
